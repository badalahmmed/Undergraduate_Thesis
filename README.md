# Development of PLC based Several Automatic Measurement and Monitoring System.
Programmable Logic Controller (PLC) is the typical and is most useful at industrial field.
It is invented to replace the necessary sequence relay circuit for machine control. In machining, packaging, materials handling, automated assembly or countless other industries
applications the PLC is most efficient considering money and time than any other control. As more complex functions are used the more complex model of the PLC must be
used. The instruction is given by Programming with Ladder Logic. Fortunately most
PLCs have software which converts Ladder Diagram into Code and is work by continuously scanning the program. In any production line, machine function or process can
be greatly enhanced using this type of control system. However, the biggest benefit is
using a PLC is the ability to change and replace the operation or process while collection and communicating vital information. The modification of programming is possible
without changing the components. They have the advantages of an all in one package,
typically with display and buttons. Supervisory Control And Data Acquisition (SCADA)
system for example Human Machine Interface (HMI) makes is more preferable for real
time control of the process parameters. A PLC these days can complete price wise and
functionally with this controllers especially if more than one controller is needed. Unlike
a personal computer through the PLC is designed to survive in a rugged industrial atmosphere and to be very flexible in how it interfaces with inputs and outputs to the real
world. PLC is on the right task as an industrial controller and increases a wide range of
use. Thus it is one of the most typical factory automating controllers
